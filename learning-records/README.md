# learning-records/

Two kinds of state live here:

1. **Learning records** — `0001-slug.md`, `0002-slug.md`, … written **only when learning is demonstrated** (quiz passed, vocabulary correctly produced, misconception corrected). Per the teach skill: coverage is not learning; wait for evidence.

2. **REVIEW-SCHEDULE.md** — the spaced-repetition ledger: which material (lesson vocabulary, grammar points, weak items) is due at +1 / +3 / +7 / +14 / +30 / +60 days.

A per-lesson **LERNSTAND summary** (position, scores, mistakes, weaknesses, next reviews) is maintained in the chat and mirrored into each learning record at lesson completion.
