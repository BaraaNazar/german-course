6 · Quiz — Selbsttest

Multiple Choice.

Erst entscheiden, dann Schlüssel aufdecken. Bestanden ab 4/6.

  1. der / die / das? ___ Portfolioa) die   b) das   c) der
  2. der / die / das? ___ Entwurfa) das   b) der   c) die
  3. Plural: überarbeiten → die ___a) die Väter   b) die Mütter   c) arbeitet über
  4. Was bedeutet „das Portfolio“?a) father   b) mother   c) brother   d) portfolio
  5. Was bedeutet „der Entwurf“?a) brother   b) sister   c) draft   d) mother
  6. Translate: „passive frame.“a) Im Folgenden wird untersucht …   b) Die Ergebnisse deuten darauf hin, dass …   c) undefined
Antworten & Erklärungen — erst nach dem Versuch öffnen!
  1. b) das — das Portfolio — lerne Nomen immer mit Artikel.
  2. b) der — der Entwurf — lerne Nomen immer mit Artikel.
  3. c) arbeitet über — überarbeiten → arbeitet über.
  4. d) portfolio — das Portfolio = portfolio.
  5. c) draft — der Entwurf = draft.
  6. a) Im Folgenden wird untersucht … — Muster: Im Folgenden wird untersucht …
