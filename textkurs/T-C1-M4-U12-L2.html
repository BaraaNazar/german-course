4 · Grammatik

Konjunktiv I: volles System

Alle Formen + Ersatz durch Konjunktiv II bei Formgleichheit.
Muster: sei · habe · könne · müsse · werde · wisse — gehe→ginge? (KII-Ersatz bei Gleichlaut)
Sie erklärte, sie wisse von nichts.
wisse = KI von wissen.
Er sagte, er gehe (ginge) nach Berlin.
KI/KII-Ersatzform.
✗ Er sagt, dass er geht (Distanz fehlt). → Er sagt, dass er gehe.
Distanz wahren: KI oder KII-Ersatz.

6 · Quiz — Selbsttest

Multiple Choice.

Erst entscheiden, dann Schlüssel aufdecken. Bestanden ab 4/6.

  1. der / die / das? ___ Schreibformata) das   b) der   c) die
  2. der / die / das? ___ Textsortea) der   b) die   c) das
  3. Plural: die Sprechprüfung → die ___a) die Brüder   b) die Sprechprüfungen   c) die Mütter
  4. Was bedeutet „das Schreibformat“?a) brother   b) sister   c) writing format   d) mother
  5. Was bedeutet „die Textsorte“?a) son   b) text type   c) brother   d) sister
  6. Translate: „wisse = KI von wissen.“a) Sie erklärte, sie wisse von nichts.   b) Er sagte, er gehe (ginge) nach Berlin.   c) undefined
Antworten & Erklärungen — erst nach dem Versuch öffnen!
  1. a) das — das Schreibformat — lerne Nomen immer mit Artikel.
  2. b) die — die Textsorte — lerne Nomen immer mit Artikel.
  3. b) die Sprechprüfungen — die Sprechprüfung → die Sprechprüfungen.
  4. c) writing format — das Schreibformat = writing format.
  5. b) text type — die Textsorte = text type.
  6. a) Sie erklärte, sie wisse von nichts. — Muster: Sie erklärte, sie wisse von nichts.
