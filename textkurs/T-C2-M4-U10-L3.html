4 · Grammatik

Wissenschaftlicher Stil

Präzise, distanziert, belegt — Hedging inklusive.

hedged claim.

passive frame.
✗ Ich beweise, dass … (zu absolut). → Die Daten legen nahe, dass …

6 · Quiz — Selbsttest

Multiple Choice.

Erst entscheiden, dann Schlüssel aufdecken. Bestanden ab 4/6.

  1. der / die / das? ___ Begutachtunga) der   b) die   c) das
  2. der / die / das? ___ Kriterienrastera) die   b) das   c) der
  3. Was bedeutet „die Körpersprache? → B2“?a) son   b) —   c) brother   d) sister
  4. Was bedeutet „die Begutachtung“?a) assessment, review   b) sister   c) son   d) daughter
  5. Translate: „passive frame.“a) Im Folgenden wird untersucht …   b) Die Ergebnisse deuten darauf hin, dass …   c) undefined
  6. Was bedeutet „das Kriterienraster“?a) sister   b) son   c) assessment rubric   d) brother
Antworten & Erklärungen — erst nach dem Versuch öffnen!
  1. b) die — die Begutachtung — lerne Nomen immer mit Artikel.
  2. b) das — das Kriterienraster — lerne Nomen immer mit Artikel.
  3. b) — — die Körpersprache? → B2 = —.
  4. a) assessment, review — die Begutachtung = assessment, review.
  5. a) Im Folgenden wird untersucht … — Muster: Im Folgenden wird untersucht …
  6. c) assessment rubric — das Kriterienraster = assessment rubric.
