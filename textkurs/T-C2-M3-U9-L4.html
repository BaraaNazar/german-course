4 · Grammatik

Wissenschaftlicher Stil

Präzise, distanziert, belegt — Hedging inklusive.
Muster: Nominalstil + Passiv + „deutet darauf hin“ + präzise Verben
Die Ergebnisse deuten darauf hin, dass …
hedged claim.
Im Folgenden wird untersucht …
passive frame.
✗ Ich beweise, dass … (zu absolut). → Die Daten legen nahe, dass …
Wissenschaft: Abschwächung statt Beweis.

Multiple Choice.

Erst entscheiden, dann Schlüssel aufdecken. Bestanden ab 4/6.

  1. der / die / das? ___ Diskursanalysea) die   b) das   c) der
  2. der / die / das? ___ Systematika) das   b) der   c) die
  3. Was bedeutet „robust“?a) robust   b) sister   c) son   d) daughter
  4. Was bedeutet „die Diskursanalyse“?a) son   b) daughter   c) child   d) discourse analysis
  5. Translate: „hedged claim.“a) Die Ergebnisse deuten darauf hin, dass …   b) Im Folgenden wird untersucht …   c) undefined
  6. Was bedeutet „die Systematik“?a) daughter   b) systematics   c) sister   d) son
Antworten & Erklärungen — erst nach dem Versuch öffnen!
  1. a) die — die Diskursanalyse — lerne Nomen immer mit Artikel.
  2. c) die — die Systematik — lerne Nomen immer mit Artikel.
  3. a) robust — robust = robust.
  4. d) discourse analysis — die Diskursanalyse = discourse analysis.
  5. a) Die Ergebnisse deuten darauf hin, dass … — Muster: Die Ergebnisse deuten darauf hin, dass …
  6. b) systematics — die Systematik = systematics.
