## 1. Text lesson format (every `T-…-L….html` (in diesem Ordner))

Pure HTML + CSS, zero interactivity: styled with the shared [../assets/styles.css](../assets/styles.css) (`.tx-*` components), printable, works offline by double-click. No reveal buttons, no scripts — the only feedback loop is the chat.

1. **Kopf** — position `Textkurs · Level → Modul → Unit → Lektion`, duration (~15–25 min)
2. **Lernziele** — in English
3. **Dialog** — German lines, each immediately followed by its English translation
4. **Vokabeln** — table: German (article + noun) | plural | English | example + translation
5. **Grammatik** — meaning → pattern table → examples → common mistakes (English explanations, German data)
6. **Aussprache** — precise IPA descriptions (no audio; check Forvo/Wiktionary links when given)
7. **Übungen** — written production tasks (fill-in, translation, transformation, sentence building) — with click-to-reveal answer key
8. **Quiz** — 5–8 **multiple-choice** items with explanations — self-test, key hidden until you open it (pass ≥ 70%)
9. **Externe Praxis** — one exact external assignment (usually Nicos Weg topic)
10. **Nächster Schritt** — pointer to next lesson

### Fun components (standard kit of every generated lesson)

- **Mermaid-Diagramme** — journey maps with your current position + decision trees for grammar choices (rendered via Mermaid CDN; offline the source code remains visible)
- **Flashcards** — pure CSS flip cards (click to turn, no JavaScript), print-optimized as cut-out sheets
- **Fun-Rotation** — 🧩 Mini-Rätsel · 🇩🇪 Kulturtipp · 🎯 Mini-Challenge + Sammel-Badges · Dialog-Variationen · Selbst-Check-Leitern
- **Grammar on every page:** all 504 lesson pages A1–C2 carry their complete grammar card(s) — meaning, pattern, examples, common mistake and a Mermaid diagram — generated from `tools/grammar-data.mjs` (58 topics; language policy applied: A1/A2 English · B1 German+EN · B2–C2 German). Unit reviews (L8) repeat their unit topics; exams show a level recap.
- **Grammar reference:** [../reference/grammar-a1.html](../reference/grammar-a1.html) — the 13 A1 topics in depth; a2+ references werden bei Erreichen des Levels ergänzt
- Full lesson coverage exists as pages from **A1 to C2** (this folder): authored lessons show full content; future lessons are plan-pages generated by `tools/gen-text-lessons.mjs` (status 🚧) and get their full content sequentially via `/teach` — quality over batch

## 2. Quiz & exam system (self-learner mode)

The learner studies **without a teacher for normal lessons**:

- **Lesson quiz = MCQ self-test.** Multiple choice with click-to-reveal answer key (`<details>`). Rule: decide first, then open the key. Pass ≥ 70% (e.g. 5/7) before moving on.
- **Übungen** also carry a click-to-reveal key.
- **Unit exams, module exams and level exams take place in the chat.** Every `…-L8` (Review + Unit Test) page carries a prominent note: *Unit finished → come to the chat for your Unit-Prüfung.* Passing (≥ 75%) unlocks the next unit.
- The chat teacher remains available any time for questions, remediation and exam sessions — but never grades regular lesson quizzes.
- Advancement criteria (skill-based, per level) unchanged.

| Level | Instruction | Glosses |
|---|---|---|
| A1–A2 | English-led, German content fully glossed | every German sentence translated |
| B1 | ~60/40 German/English | key sentences translated |
| B2 | ~50/50 | vocabulary glossed on first use |
| C1 | German-led, English for nuance contrasts | rarely |
| C2 | German only + contrastive notes | on demand |

## 4. Skills balance in a text medium

Reading & writing are native to this track and get extra volume (short translations every lesson, writing tasks every 2nd lesson). Listening & speaking are not skipped: each unit assigns **external audio work with concrete tasks** (e.g. "Nicos Weg episode X: watch twice, then answer these 3 questions in chat") and **typed roleplay** with the teacher (chat conversation at your level). Pronunciation: IPA-precise notes + Forvo checks + self-recording assignments.
