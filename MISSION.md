# Mission: German A1 → C2

## Why
I want German for **genuine real-world communication**: to understand and be understood in a German-speaking environment — at work, in offices, with friends — and eventually to handle sophisticated native content (films, literature, debate) with ease. Passing exams is a checkpoint, never the point.

## Success looks like
- Follow natural-speed conversations, podcasts, films and lectures without English crutches
- Speak spontaneously and accurately in daily life and professional settings
- Write clear, correct, appropriately-register German (messages → emails → essays → professional documents)
- Read news, literature and specialist texts comfortably
- Function independently in a German-speaking country (appointments, authorities, work, social life)
- Reach demonstrated C2 competence: nuance, style, idiom, register control

## Constraints
- Solo independent learner; teacher = AI agent using the `teach` skill (HTML lessons in `lessons/`)
- ~30–60 minutes per day (Essential 20 / Standard 45 / Optional 60–90)
- Started from A1 / zero German (September 2026)
- Language mix: German + English at A1 → predominantly German by B1/B2 → almost entirely German at C1/C2

## Out of scope
- Building a commercial learning application or React project (browser HTML lessons are presentation only)
- Certificate-chasing: exam preparation only in the final stretch of each CEFR level
- Other languages or unrelated topics in this workspace
